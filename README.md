# TalentAI – AI-Based Resume Screening and Candidate Shortlisting System

TalentAI is a resume screening and candidate shortlisting project designed to simplify the initial recruitment process. It helps recruiters analyze resumes against job requirements, identify relevant skills, and shortlist candidates based on their matching scores.

## 🚀 Features

- Upload and screen resumes.
- Extract information from PDF resumes.
- Match candidate skills with job requirements.
- Calculate resume matching scores.
- Rank candidates based on their matching results.
- Display screening results through an interactive dashboard.
- View shortlisted candidates.
- Export candidate results to Excel.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Main programming language |
| Streamlit | Interactive web application |
| NumPy | Numerical operations |
| Pandas | Data processing |
| PyPDF2 | PDF text extraction |
| Matplotlib | Data visualization |
| Jupyter Notebook | Development and experimentation |

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/mayanksatwal/AI-Resume-Screening-System.git
```

### 2. Open the project directory

```bash
cd AI-Resume-Screening-System
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
python -m pip install streamlit numpy pandas PyPDF2 matplotlib openpyxl
```

### 6. Run the application

```bash
python -m streamlit run app.py
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:8501
```

## 📊 Project Workflow

1. Upload candidate resumes in PDF format.
2. Extract text and identify relevant skills.
3. Compare extracted skills with job requirements.
4. Calculate candidate matching scores.
5. Rank candidates based on matching results.
6. Display screening results and shortlisted candidates.
